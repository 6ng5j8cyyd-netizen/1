# Steamplay 簡易使用說明

讓 Mac（含 Mac mini M 系列）玩 Steam 上「只有 Windows 版」的遊戲。

## 先搞懂一件事（30 秒）

你 Mac 上現在裝的 Steam 是 **macOS 版**，它只能玩有出 Mac 版的遊戲。
Windows 專屬遊戲需要透過 **Windows 版 Steam** 執行——Steamplay 會在 Mac 裡建一個
Windows 相容環境，把 Windows 版 Steam 裝進去。兩個 Steam 可以並存、登入同一個帳號。

## 第一次安裝（只需做一次，約 10–20 分鐘）

打開「終端機」（Terminal），依序貼上：

```bash
git clone https://github.com/6ng5j8cyyd-netizen/1.git steamplay && cd steamplay
./install.sh          # 安裝 steamplay 指令
steamplay setup       # 安裝 Wine 引擎（會自動裝 Rosetta 2 等，需等幾分鐘）
steamplay install-steam   # 下載並安裝 Windows 版 Steam
```

`setup` 完成時會自動建立「**Steamplay 控制台**」App——之後你就不需要終端機了。

## 之後每天怎麼玩（免終端機）

1. 按 **⌘ + 空白鍵**（Spotlight），輸入 **Steamplay**，打開「Steamplay 控制台」。
2. 點「**🎮 啟動 Windows Steam**」，登入你的 Steam 帳號。
3. 在 Steam 視窗裡照常瀏覽、下載、按「開始遊戲」——跟在 Windows 電腦上一模一樣。

想更快？在控制台選「**🔗 建立雙擊捷徑**」：

- 「Windows Steam」→ 桌面等級的捷徑，雙擊直接開 Steam（可拖進 Dock）
- 「單一遊戲」→ 輸入遊戲的 AppID，做出雙擊直接進遊戲的捷徑
- 「開機自動啟動」→ 開機就自動把 Steam 掛在背景

> 捷徑放在「使用者/應用程式」（`~/Applications`）資料夾。注意 Finder 側邊欄的
> 「應用程式」是另一個系統資料夾（`/Applications`），用 Spotlight 搜尋最不會迷路。

## 控制台選單總覽

| 選項 | 用途 |
|---|---|
| 🎮 啟動 Windows Steam | 日常入口，開 Steam 玩遊戲 |
| 🚀 直接啟動遊戲 | 輸入 AppID 跳過 Steam 介面直接進遊戲 |
| 📦 步驟一／步驟二 | 第一次安裝用（裝 Wine 引擎、裝 Windows Steam） |
| 🔗 建立雙擊捷徑 | 做出免終端機的 App 圖示 |
| 🛠 修正工具 | 遊戲跑不起來時的一鍵修復（見下） |
| ⚙️ 效能設定 | 開關 FPS 顯示、Retina、切換同步機制 |
| 🩺 系統診斷 | 檢查環境哪裡有問題 |
| ⛔ 強制關閉 | 遊戲卡死時按這個 |

## 遊戲跑不動？三步排查

1. **先按「🩺 系統診斷」**——它會直接告訴你缺什麼。
2. **對症下藥（🛠 修正工具）**：
   - 畫面破圖、FPS 很低（較舊的遊戲）→ `dxvk`
   - 錯誤訊息提到缺 `VCRUNTIME…dll` → `vcrun2022`
   - 中文變成方塊 → `cjkfonts`
3. **效能不夠**：⚙️ 裡把 Retina 關掉（預設已關）、開 HUD 看 FPS 瓶頸。
   （Apple Silicon 上預設就用效能最好的 Apple GPTK／D3DMetal 引擎，不用另外設定。）

## 常見問題

**Q：要每次都打指令嗎？**
不用。裝好之後日常只要雙擊「Steamplay 控制台」或「Windows Steam」捷徑。

**Q：帳號、存檔怎麼辦？**
用你原本的 Steam 帳號登入即可。支援 Steam 雲端存檔的遊戲，存檔會自動同步。

**Q：什麼遊戲玩不了？**
帶核心層反作弊的多人遊戲（PUBG、Apex、Valorant 這類）在任何 Wine 類工具
（包括付費的 CrossOver）上都無法上線，這是平台限制。這類遊戲建議改用
GeForce NOW 之類的雲端串流。

**Q：會弄壞我原本的 macOS 版 Steam 嗎？**
不會。Windows 版 Steam 活在自己的隔離環境（`~/.steamplay`）裡，
想整個移除就刪掉該資料夾與 `~/Applications` 裡的捷徑即可。

**Q：Dock 上出現「wine64-preloader」，按了沒反應？**
正常現象。它是 Wine 的核心程序——所有 Windows 程式（Steam、遊戲、背景服務）
在 macOS 眼中都掛在這個名字下。它不是可點開的 App，按了沒反應是預期的。
Steam 開著時放著不管即可；確定都關完了還在的話，執行 `steamplay kill` 清掉。
想看它背後實際跑著什麼：`steamplay ps`。

**Q：遊戲很卡？**
先確認遊戲內解析度設 1920×1080（別用 Retina 原生解析度）、
關閉光線追蹤；用 ⚙️ 開 HUD 觀察 FPS；DX12 遊戲換 GPTK 引擎通常有感提升。
